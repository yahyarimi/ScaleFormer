# SCALE-Former bibliography audit

Initial locked core reference set for the manuscript.

## Groups
- OFDM deep learning: `ye2018deepofdm`
- CSI feedback/reconstruction: `wen2018csinet`, `yang2019deepcmc`
- Review/background: `mashhadi2020survey`
- Transformer/attention CSI: `cui2022transnet`, `mourya2023stnet`, `kim2023tpca`, `yue2024transformerreceiver`, `yin2025flowmat`
- Measured/real-world validation: `shehzad2025empirical`, `huang2025digitaltwin`
- DICHASUS: `euchner2021dichasus`, `euchner2021dichasus005x`
- Transformer foundation: `vaswani2017attention`

## Guardrails
1. Do not claim SCALE-Former is the first Transformer for CSI estimation, feedback, or reconstruction.
2. Distinguish feedback/compression from sparse-observation reconstruction.
3. Cite both the DICHASUS sounder paper and the specific dichasus-005x dataset DOI.
4. Do not call controlled masks operational DICHASUS pilot patterns.
5. Use “dense measured reference CSI,” not “physical ground truth channel.”
6. State transfer only across tested antenna/frequency configurations.
7. Retain the accuracy-efficiency trade-off and negative block-mask result.
